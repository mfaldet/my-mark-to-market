# Brand files

- `mark.svg`: the scales glyph next to the app's name, also the browser-tab icon
- `app-icon.svg`: the home-screen icon and link-preview image

`apple-touch-icon.png`, `icon-512.png`, `/logo.png` and `/favicon.ico` are
made from these two files. If the logo changes, replace the SVGs and
regenerate the PNGs.
